Alcance

Solo lo que ya existía en el portal PHP y se migró a Java sobre los mismos web services ORDS (es decir, mismos datos que ve el PHP). Lo nuevo del portal (accidentes con seguimiento, maternidad, restricciones, causas, consumibles, dashboard, administración, examen inicial, OCR) no entra aquí.

Criterio de aceptación general: lo que se captura en Java lo debe ver el PHP igual (y al revés) mientras convivan, porque escriben en los mismos WS. Por eso el grupo 9 (paridad) es el que decide si se puede apagar el PHP.
