Cómo se lee el avance. Cada tarea vale lo mismo. El porcentaje global es tareas Hecho entre el total; cada fase tiene el suyo. Para actualizar basta cambiar la etiqueta de la columna Estado (hecho, curso, bloqueado, pendiente) y recargar la página: las barras y los contadores se recalculan solos. Un formato cuenta como "sale lleno" cuando todas sus tareas están en Hecho.

2. Plan de trabajo

Seis fases. Las primeras aprovechan lo que ya existe (impresión HTML con window.print(), encabezado de formato reutilizable, ficha del trabajador); la fase 5 es el módulo nuevo. La columna Formatos dice a qué formato abona cada tarea.

Decisión de mecánica. Los formatos se reproducen como página HTML imprimible (el PDF lo hace el navegador), igual que hoy el expediente del examen. No se rellena el Excel: obligaría a abrir Excel para imprimir y complica las firmas. Base de datos: todo lo nuevo va a la base del portal (tablas SERV_MED_* dentro de BIOMETRICO); se entrega el .sql y lo corre el usuario. No se modifica ningún WS de ORDS.
