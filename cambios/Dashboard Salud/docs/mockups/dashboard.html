Análisis Ejecutivo

Insights derivados de los datos capturados

AIFA concentra el 24.2% de las atenciones (3,052 de 12,613) y el mayor número de accidentes (42).
Los días de incapacidad de junio (2,394) subieron 16.9% frente a mayo, el valor más alto del año.
Las tres principales causas — vacuna/seguimiento (1,982), digestivo (1,809) y respiratorio (1,775) — suman el 44% del total.
El accidente de trayecto genera 2,600 días perdidos, 79% más que el accidente laboral (1,454).
Las lesiones graves son marginales: 0 amputaciones y 0 fracturas en el acumulado del año.
