Auditoría

Bitácora única para toda la plataforma · solo visible para perfiles autorizados

La bitácora todavía no tiene eventos. Se llena con el uso del portal: cada alta, cambio o borrado, cada inicio de sesión y cada exportación queda registrada con usuario, fecha, módulo, registro y dirección IP. No hay histórico que migrar: el portal PHP no auditaba.
